        ❓ Como usar

        1. Cadastre um software (categoria de contingência): nome, descrição, ícone opcional.

        2. Toque no software para abrir o índice de tutoriais dele, e adicione os títulos (ex: "Parte 1 – ...").

        3. Toque num título para cadastrar as imagens (com legenda), o vídeo e o passo a passo dele.

        4. Exportar: baixa um .zip com index.html, style.css, script.js e todos os arquivos de mídia anexados, prontos para hospedar.

        Importação em lote (JSON): baixe o modelo, preencha os dados (textos) e importe para preencher tudo de uma vez. As imagens/vídeo ainda precisam ser anexados manualmente depois, pois um JSON não carrega arquivos binários.

        Abrir script.js existente: carrega um arquivo já gerado para editar/atualizar. Os TEXTOS voltam todos; IMAGENS e VÍDEO aparecem só pelo nome (o navegador não tem acesso a esses arquivos) — se quiser trocá-los ou incluí-los no próximo export, anexe-os de novo nessa tela.

        Nota técnica: os arquivos de mídia devem ficar na MESMA pasta do index.html (sem subpasta) — é assim que o modelo original carrega as imagens, apesar do comentário antigo mencionar uma pasta "imagens".
